# claude-sonnet-5-5 at medium effort

Status: accepted. Supersedes [0002](0002-model.md).

## Context

0002 chose `claude-sonnet-5` at `effort: "medium"` for a dialogue-and-extraction workload that
calls tools on most turns. `claude-sonnet-5-5` is the next model in the same line at the same
price ($2/$10 per MTok, cache reads $0.20), with the same tokenizer, 1M context and 128k output
([migration guide](https://platform.claude.com/docs/en/about-claude/models/migration-guide)).

## Decision

`claude-sonnet-5-5`, `effort: "medium"`, server-side refusal fallback (`fallbacks: "default"`).

- **Effort stays `medium`.** Levels are recalibrated on Sonnet 5.5; `medium` is the documented
  starting point for multistep tool use, which is what every turn here is. `low` remains the next
  thing the evaluation ([`docs/evaluation.md`](../evaluation.md)) should measure.
- **Thinking stays adaptive by omission.** `thinking: {type: "disabled"}` is rejected on this model;
  the code never sets `thinking` or `reasoning`, and `@ai-sdk/anthropic` only sends `disabled` for
  `reasoning: "none"`.
- **`tool_choice` stays `auto` or `none`.** Forced `any`/`tool` is rejected on this model; the last
  step's `toolChoice: "none"` is accepted.
- **Refusal fallback on.** A refused request ends with `stop_reason: "refusal"` and no text;
  `fallbacks: "default"` lets the API retry the categories it can route, and costs nothing on the
  requests that are not refused.
- `@ai-sdk/anthropic` 4.0.54 resolves `claude-sonnet-5-5` through its `claude-sonnet-5` capability
  entry (substring match): 128k output, `xhigh` effort, sampling parameters rejected — all true of
  Sonnet 5.5.

## Consequences

- Thinking blocks are tied to the model and the conversation on Sonnet 5.5. The route never sends
  reasoning to the client (`sendReasoning: false`), so earlier turns replay without thinking
  blocks and nothing edits a block the API would check. Within a turn, the AI SDK appends steps
  without rewriting the system prompt, the tools or earlier messages.
- Text the model writes between tool calls can come back as `thinking` blocks when it runs longer
  than a sentence or two. The interface renders text parts only, so a long lead-in before a card or
  the recap would not show. The prompt keeps that text to one sentence; a live run should confirm
  it before relying on it.
- The minimum cacheable prefix drops to 512 tokens; the cached system prompt is well above either
  threshold.
